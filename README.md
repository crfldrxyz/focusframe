# FocusFrame

A minimal, beautiful single-page focus tool.

**What it does**
1. User enters one clear task.
2. Starts a 25-minute focus timer.
3. At the end, writes a short reflection.
4. Can export the session as Markdown or copy it.

**Tech constraints (non-negotiable for this experiment)**
- Pure frontend only (HTML/CSS/JS or minimal Next.js)
- No backend, no user accounts, no database
- localStorage for persistence
- Must look clean and calm
- Must work on mobile
